Privacy Policy

ExtractFlow AI is designed for maximum privacy. Here's exactly how your data is handled:

Data Processing

  • 100% Local Processing: All AI inference runs on your machine. Your documents are never sent to any server unless you explicitly configure a cloud API.
  • No Telemetry: ExtractFlow does not collect any usage data, analytics, or telemetry. Zero.
  • No Accounts Required: No registration, no login, no email collection. The optional login feature stores credentials locally in SQLite on your machine only.
  • Local Storage Only: All documents, chat history, and settings are stored in a local SQLite database on your computer. Nothing is uploaded anywhere.

Cloud API Usage

If you choose to connect a cloud API (Gemini, OpenAI, etc.):

  • Your API key is stored locally in your SQLite database
  • When you chat, your message and document context are sent to the cloud provider you configured
  • This is entirely voluntary — the app works fully offline without any cloud connection
  • You should review the privacy policy of each cloud provider you connect

Open Source Transparency

The entire codebase is open source on GitHub. You can audit every line of code to verify these claims.

Data Retention

All data is stored locally on your machine. You can delete any document, chat history, or configuration at any time. Uninstalling the application removes all local data.

Children's Privacy

ExtractFlow is not directed at children under 13. Since it runs entirely locally with no data collection, there are no privacy concerns for any age group.
